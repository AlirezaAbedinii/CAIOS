## The narration as one text

This is CAIOS, the Canadian Artificial Intelligence Operating System. It is AI infrastructure for medical and neuroscience research. It runs in Canada, and nothing a researcher does here is handed to a commercial service. There are three ways to work with it: no code, low code, and high code.

A new colleague signs up with nothing more than an email address. Until someone approves the request, they can sign in, but they cannot see or use anything. An administrator reviews the request and approves it with a single click. The next time they sign in, the platform is open to them.

First, no code. The catalogue offers a curated set of open language models. A researcher picks one and fills in a short form. There is nothing to install. A few minutes later, the model is running on the lab's own GPU, at its own private address. Here, it summarises a radiology note in a single sentence. The note never left this cluster, and there is no charge per question.

Next, low code. This object detection model comes from the same catalogue. This time, it is published as a serverless service. It only runs when a request arrives. The service gets its own endpoint and access key. One request from a script sends in a photograph. Back come the objects the model found, where they are, and how confident it is.

Finally, high code. The same model again, this time opened as a full JupyterLab workspace, with its own code and environment. It finds the bus and the people in this photograph, and draws them. From the same notebook, we can call the serverless service from a moment ago, and ask our private language model to describe what was found. Three ways in, one platform, and nothing leaves it.

Federated learning is what makes this matter for hospitals. Three hospital sites train one shared model. Each one trains on brain MRI scans that never leave its own machine, and shares only what its model has learned. A coordinating server combines those updates, round after round. The shared model reaches 85.3 percent accuracy. The best hospital working alone reaches 80.6. Pooling every scan in one place, which no hospital is permitted to do, reaches 86.5.

All of this runs on a seven-node cluster on Compute Canada's Arbutus cloud, under the lab's own research allocation. CAIOS. Private AI infrastructure for medical and neuroscience research, built in Canada.
